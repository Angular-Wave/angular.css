Use native `kbd` elements with `class="kbd"`. Group shortcuts with
`class="kbd-group"`.

```html
<span class="kbd-group">
  <kbd class="kbd">Ctrl</kbd>
  <kbd class="kbd">K</kbd>
</span>
```
