Use native table elements with part classes for styling hooks.

```html
<figure class="table-container">
  <table class="table">
    <thead class="table-header">
      <tr class="table-row">
        <th class="table-head">Invoice</th>
      </tr>
    </thead>
  </table>
</figure>
```
